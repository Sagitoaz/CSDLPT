5. Sequence tạo donation

sequenceDiagram
    autonumber
    actor Donor
    participant FE as Frontend
    participant API as Backend API
    participant Camp as Campaign Service
    participant Donate as Donation Service
    participant DB as MongoDB PRIMARY
    participant SEC as MongoDB SECONDARY nodes

    Donor->>FE: Nhap form quyen gop
    FE->>API: POST /api/donations
    API->>API: Validate Zod: donorName, donorEmail, amount, campaignCode
    API->>Camp: Kiem tra campaignCode ton tai
    Camp->>DB: findOne campaigns by code
    DB-->>Camp: Campaign
    API->>API: Kiem tra isActive = true
    API->>API: Kiem tra startDate/endDate neu co
    API->>Donate: Tao donation voi status = pending
    Donate->>DB: insertOne donations
    DB-->>SEC: Replicate oplog
    DB-->>Donate: Created
    Donate-->>API: Donation pending
    API-->>FE: 201 Created
    FE-->>Donor: Hien thi ket qua / reload danh sach

6. Sequence duyệt donation

sequenceDiagram
    autonumber
    actor Staff as Staff/Admin
    participant FE as Frontend Admin
    participant API as Backend API
    participant RBAC as JWT and RBAC Middleware
    participant Donate as Donation Service
    participant DB as MongoDB PRIMARY
    participant SEC as MongoDB SECONDARY nodes
    participant Stats as Stats Aggregation

    Staff->>FE: Chon verified hoac rejected
    FE->>API: PATCH /api/donations/:id/status
    API->>RBAC: Kiem tra JWT va role admin/staff
    RBAC-->>API: Cho phep
    API->>API: Validate status
    API->>Donate: Update donations.status
    Donate->>DB: updateOne donation
    DB-->>SEC: Replicate oplog
    DB-->>Donate: Updated
    Donate->>Stats: Doc lai so lieu moi
    Stats->>DB: aggregate donations by status and amount
    DB-->>Stats: Ket qua thong ke
    API-->>FE: 200 OK
